# KevenOS design system

The source of truth for the public identity is [`brand/BRAND.md`](../brand/BRAND.md).
Product interfaces use a dark event-night foundation, restrained cyan/violet
motion cues and mint for ready or accepted states.

## Semantic tokens

| Purpose | Value |
|---|---|
| Background | `#07111F` |
| Surface | `#0B1B30` |
| Primary text | `#F8FAFC` |
| Secondary text | `#B8CBE0` |
| Accent | `#22D3EE` |
| Secondary accent | `#8B5CF6` |
| Positive | `#8AE9D9` |
| Border | `#284B6F` |

Interfaces must retain keyboard navigation, visible focus, at least 4.5:1 text
contrast and reduced-motion behavior. Mobile layouts prioritize the current
action; desktop and hall layouts add context without changing authority.
