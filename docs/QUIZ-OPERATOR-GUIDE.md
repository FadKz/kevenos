# Quiz operator quick guide

Open **Home → Event Operations → Quiz**. Check the Rehearsal pill before practising. The current event section is shown above the four tabs.

## 1. Run quiz

Start in **Setup** and enable the quiz. Return to **Run quiz**, invite people to join, then open the practice warm-up when the room is ready. Follow the suggested next action as the programme progresses.

**Send question** puts the question on eligible participants’ phones. While it is open, watch the response count and timer. **Add 15 seconds** gives more time. **Stop accepting answers** keeps submitted answers. **Cancel question** excludes that question and its points; confirm only when you mean to discard it. The hall keeps results hidden until the question’s scheduled end; participants can review a scored answer after it is stopped.

Warm-up carries no points. During the scoring break, the console offers the post-test and an optional catch-up after judging has finished. Confirm any missing-sheet exception only after checking with the Scoring Desk. Quiz invitations appear in the app; they are not email invitations.

## 2. Timeline

The current section is selected initially. Choose another section or **All sections** to plan ahead. Preview each question on a phone, edit its draft, skip it, or choose **Change time or section**.

Enter the number of **minutes after the section starts**. To delay the remaining questions together, select **Also move later unsent questions in this section**. Review every before/after change, then apply. A five-minute delay to the first cue moves the later unsent cues five minutes too. A question moved to another section is moved individually.

These are reminders, not automatic sends. Questions still need **Send**. The event agenda is managed separately through **Manage event programme**; moving the actual section naturally moves its relative quiz reminders. A concurrent organizer edit requires loading the latest question before previewing again.

## 3. Results

See live participation and responses, then select a question to inspect its answer distribution. Release waiting-time/post-test answers when ready. Show eligible results on the hall screen or return the hall to the programme. Controls explain why an action is unavailable during judging or before the Final is ready.

Use Add 15 seconds before a scored question closes. A scored question cannot be resent after its answer has been revealed. Unscored polls may still offer resend. Reset is an explicit recovery action; if an answer was disclosed, edit the replacement prompt before scoring another attempt. A reset excludes the old run’s points and allows a fresh run; the old answers remain in history. Final votes can be resent only when the phase and finalist lineup permit it.

Before announcing the Champion, release waiting-time answers, release the post-test, resolve predictions and show People’s Choice (or cancel any unwanted run). The reveal waits for these sent questions to be resolved, including unscored Final votes, so participants are not left waiting for results. Organizer reports contain aggregates. Question CSV files are an audit history and may include cancelled-run response counts; those answers do not count toward scores.

## 4. Setup and recovery

The whole-quiz reset is under **Reset and recovery**. Export reports first if needed. It requires a reason and typing **RESET QUIZ**. It affects only the selected workspace and keeps quiz sign-ups, question edits and prize. It clears current quiz runs/results and turns the quiz off. Roster, passwords, event programme and pitch scores are retained.

The last three snapshots are retained. **Restore quiz archive** is offered only for the latest reset when no intervening quiz activity would be overwritten. It requires a reason and **RESTORE QUIZ**. Restored questions stay closed, the quiz stays off, and the hall stays on the programme. Re-enable deliberately when ready. Do not use full reset for an ordinary stopped or incorrect question.

## Quick recovery choices

| Situation | Action |
| --- | --- |
| People need a little longer | Add 15 seconds |
| Enough answers received | Stop accepting answers |
| Wrong question sent | Cancel question |
| Same question needs a fresh scored attempt | Results → additional actions → Reset question |
| Some people missed it | Resend, when offered |
| Section is running late | Timeline → change minutes → preview later cues |
| Start a new rehearsal quiz | Setup → Reset and recovery |
| Accidental full reset | Restore the latest archive before doing anything else |

For spontaneous sentiment polls or feedback packs, open **Audience questions**, not Quiz. These questions carry no points and require no quiz opt-in. Save a draft, review it, then Send for the chosen duration. Close keeps responses; Cancel withdraws the pack. Share results only when ready. Written feedback remains private to staff.


## Quiz on the projector

In **Event Operations → Quiz → Run quiz**, choose **Send to phones and projector**
for a room question. The server sets the same deadline for both screens. When a
standard question closes, the projector shows the correct answer and response
counts for 15 seconds with the updated standings. The projector then returns to
the programme with the compact Quiz leaderboard. Questions with a held result
show **Results pending**. Use the existing release controls for those answers.

In the **Quiz** header, use **Show leaderboard for 15 seconds** to show the Top 10.
Use **Return hall to programme** to end it early. The Quiz board uses released
points. A presenter link without names shows team and player labels.
